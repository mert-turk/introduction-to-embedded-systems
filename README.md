## What is it?

Welcome to the Introduction to Embedded Systems series!

The goal of this series is to introduce you to the fundamentals of embedded programming in the simplest and most practical way possible. We will explore how software interacts with hardware, starting with the basics and gradually building a deeper understanding of what happens under the hood.

--

## What you should expect?
There are some fundamental topics that I believe are essential to understanding embedded systems and seeing the bigger picture. :)

The series is still a work in progress, but here are some of the topics you can explore so far:

- How GPIO works

- Pointers and memory-mapped I/O
 
- Functions and the ARM Architecture Procedure Call Standard (AAPCS)

- Structures and device drivers

- Startup code and the reset handler

- More topics will be added as the series evolves!


--

## What do you need to start?

In the course, we are using STM32F411RE Microcontroller that includes ARM-Cortex-M4 processor. So it would be very
nice to have the board for exploring things you have seen yourself throughout the course.
